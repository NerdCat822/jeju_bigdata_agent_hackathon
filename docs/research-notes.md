## 1. 대회 (DAKER 공식 데이터 + 기획서 PDF)

- 주최 제주테크노파크(제주TP), 데이터 제공 제주빅데이터센터·제주데이터허브, 운영 플랫폼 DAKER(데이콘). 「제주빅데이터센터 운영사업」(제주도 공기관 대행사업) 예산으로 추진.
- 주제: 제주 공공·민간 데이터 + 생성형 AI로 **데이터 분석 자동화 에이전트**. "이용자가 일상적인 말로 분석을 요청하면 수집·가공·결과 도출까지 처리". IT 비전문가 도민이 **센터에서 직접 실행**하는 것이 목적.
- 우수작은 **센터 오프라인 분석환경에 상시 탑재**(제주TP 보도자료). 장대교 미래융합사업본부장: "높은 코딩 장벽을 허물고 도민 누구나 제주의 귀중한 데이터를 일상에서 활용".
- DAKER 메타데이터(2026-11-06): 참가 355명, 최종 제출 21건, 초안 6건, 조회 19,835, 저장 85. 대회 유형 development/premium, 팀 1~5명.
- 단계 설정: 접수·제출(10/26 10:00~11/20 10:00) → 상호평가 ELO(11/23 12:00~11/27 10:00, 가중 0.30, blindMode, 노출 형식 pdf·github·demo) → 전문가 평가(11/23~11/27 23:59, 가중 0.70, 링크 demo·github·youtube **required**) → 최종 발표 11/30 10:00 → 발표·시상식 12/7(월) 제주TP.
- 상금: 대상 300만(제주도지사상) / 최우수 100만(제주TP원장상) / 우수 2팀 각 50만. 당선작 없으면 미시상 가능. 원천징수. 수상자 시상식 참석·발표 의무.
- 규칙 6항 결과물 소유권: "모든 결과물은 제주빅데이터센터에 소속되며, 시상작의 경우 제작자의 이름(혹은 팀명)으로 센터에서 제공될 수 있습니다." 동의 약관: 수상작은 스폰서에 5년 비독점·전세계·완전지불 라이선스(내부 연구·기술개발·시범운영 한정, 상업화는 별도 협의).

## 6. 센터 PC용 로컬 LLM 조사

- Ollama 라이브러리 확인: `qwen3:4b` 2.5GB(Q4_K_M, `4b-instruct-2507` 변형 동일 용량), `qwen3:8b` 5.2GB, `qwen3:4b-q8_0` 4.4GB, `exaone3.5:7.8b` 4.8GB(Q4_K_M), `exaone3.5:2.4b` 1.6GB, `exaone3.5:7.8b-instruct-q8_0` 8.3GB.
- 6GB VRAM 일반 가이드: 7B급은 Q4에서 짧은 컨텍스트만 안정, 8~9B는 실질 8GB 필요. GTX 1060은 CUDA CC 6.1, INT8 가속 없음 → 생성 속도 보수적으로 예상(4B Q4 ≈ 10~25 tok/s, 실측 필요).
- 결론: 기본 `qwen3:4b`(도구 호출·구조화 출력), 해설 품질용 `exaone3.5:7.8b` 선택, 3GB VRAM 대비 `exaone3.5:2.4b`. 클라우드는 Anthropic Claude(`claude-opus-5-5` 기본, 1M 토큰당 $4/$20) 선택 기능.

## 7. 조사 방법 메모

- 기획서 PDF 5p 전문 추출(pypdf) → 공모 요건 정리.
- 제주데이터허브는 Vue SPA라 HTML에 내용이 없음 → `app.*.js`에서 API 경로 추출 후 공개 엔드포인트 직접 호출(센터 테이블 목록, FAQ, 인기 데이터, 상세 API 명세). 명세서 xlsx는 센터 메뉴의 공개 다운로드 링크로 확보(저장소 미포함).
- DAKER도 SPA → `/api/hackathons/{slug}`에서 상금·규칙·평가·단계 설정(JSON) 확보. 게시판 API는 미확인(로그인 필요 추정).
- 일부 지역 언론 사이트는 봇 차단(302 → error.html)으로 다음 뉴스·뉴스서울 미러 기사로 대체 확인.
